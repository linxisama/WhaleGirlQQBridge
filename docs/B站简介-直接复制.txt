鲸鱼娘 QQ 机器人（自制，全手写）

接入方式：官方 QQ 开放平台 / 普通 QQ（OneBot 11），同一个界面切换。

主要功能
· 人设：可存多套人设，群里喊关键词自动切换，支持违禁词过滤
· 记忆：记住群友说过的事实和偏好，有群友档案、外号对照、好感度
· 表情包：自动收集群里的表情包，收到图片先识别内容再选图，支持 300 种梗图模板
· 真人感：连发合并、分句打字、防复读，被 @ 立刻回，回复后还能接着聊
· 主动行为：定时播报、冷场主动开话题、被戳一戳会回应或反戳
· 管群：管理员私聊指令、风险操作需在控制台审核、点名闸门（只在被 @ 时开口）
· 省钱：按 token 计费就压缩上下文，按次计费就减少调用次数
· 控制台：8 个页面，带「未回复诊断」，能查清一条消息为什么没回

一共 60 个插件，全部有开关和参数，不用改代码。

声明：自制程序，仅供学习和群内娱乐，不涉及破解、外挂、代刷。模型和 API 需自行配置，费用自理。
