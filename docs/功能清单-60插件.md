# 附录：60 个插件清单（按分类）

> ★ = 装好就默认开启；其余在控制台「插件」页手动打开。
> 每条只写“它能干什么”，细节见插件说明。

## 社交与群氛围（13 个）

- **主动私信**：当指定用户长时间不说话时，主动发私信关心
- **回复时机与引用**：移植自社区插件 reply-freshness：把"现在几点、群里最新一条是谁、你要回的那条还新不新鲜"算清楚，追加在当前这条消息末尾（不动系统提示词
- **复读接梗**：群里出现跟风短句时，提示AI自然融入
- **定时消息与文案推送**：在指定星期和时刻给指定群发送固定文字，或用现有模型生成文案。普通QQ接入可用；官方QQ的主动消息权限不在本功能支持范围内。每次任务独立去重
- **戳一戳概率回应**：被戳时按概率决定是否回应、反戳或忽略
- **指定群主动开话题**：在指定群聊中，长时间无消息后主动开启话题
- **消息表情回应**：普通QQ群聊专用：/贴表情 128077 或“给我点个赞”可给消息气泡贴反应；可按概率自动贴，支持AI选表情及随机模式、冷却和小时/每日上限
- **群友好感度**：移植自社区插件 affinity：自动给每个群友累积好感度 —— 发言加分、@机器人加分、接话加分，每人每天有上限防刷屏；长期不发言缓慢衰减；主人恒为满级
- **群聊复读机**：当多人说了相同的话时，机器人跟着复读。纯媒体占位（[图片]、[表情:微笑]、[语音]…）不复读 —— 多人发表情包会得到相同占位文本，复读它只是刷屏
- **跟着贴表情**：普通QQ/OneBot专用：群友给消息贴表情回应时，跟贴同一条消息的同一个表情，全程不调用模型、不发文字。当前官方QQ群聊接入不支持此动作，会保持不执行
- ★ **跨会话认人**：同一稳定用户标识的已确认偏好可用于其他会话；默认禁止把私聊记忆带入群聊。官方 QQ 不同场景标识不一致时不会猜测身份
- **问号接龙**：群里连续发问号时，机器人跟着发一个问号
- ★ **鲸鱼娘情绪与精力**：维护角色的心情、精力和压力，随时间恢复；只在消息发送成功后更新。/状态 可查看当前角色状态

## 节奏与真人感（8 个）

- ★ **回复多样化（防复读）**：回复和本会话最近几条自己的话太像时，带指令重生成一次，避免每句都是同一个开场/口头禅（例如连续回十几条"不服开帖"）
- **打字速度**：在句子之间插入打字延迟标记，模拟真人打字节奏。「媒体消息也分段」关掉时，带图片/表情的回复不再拆句 —— 否则媒体段与文字会被拆开成两条消息
- ★ **打断复读**：同一消息被多次触发时，阻止机器人重复回复
- **睡眠时段**：在指定时间段内不回复消息
- ★ **短期跟聊**：成功回复后，同一群友可在跟聊窗口内继续说话，无需重复 @；回复更简短自然。「句数上限」会真正写进提示词
- ★ **群聊上下文与回复控制**：按昵称或 @ 触发，引用近期群聊背景；支持低概率插话、会话限流、上下文预算与同一接口备用模型。插话默认关闭，换人设后旧对话不再影响新角色
- ★ **连发合并**：同一人在短时间内连续发消息时，等他发完再一起回复。被 @ 或被叫昵称时**不等待**、立刻回；其余情况对方静默 quietMs（默认 0.6 秒）就开口
- ★ **重复艾特忽略**：同一人短时间内多次@时，提示机器人冷静应对

## 图片 / 表情 / 内容（11 个）

- **Pixiv 插图**：启用后发 /插图 关键词，读取配置的Lolicon兼容服务并发送真实图片，附作品及作者来源。当前接入全年龄图片；Pixiv直连和Cookie模式尚未验证
- **偷表情包与本地收藏**：自动保存实际收到的表情图片，按内容去重，加入机器人自己的图库。支持官方QQ与普通QQ；不会写入或删除你的QQ收藏。默认只收表情/动图及小尺寸图片
- **分享卡片与网页解读**：把群友转发的分享卡片与链接整理进上下文：卡片自带的标题/描述/来源/跳转链接会被解析出来，并标出平台（B站、抖音、小红书…）
- ★ **合并转发阅读与总结**：普通QQ可读取转发ID的节点，并以限定长度的参考文本交给聊天模型阅读或总结；也支持消息内附带节点。转发图片可由视觉模型读取，截图文字可随长图分段识别
- ★ **表情包与自定义图库**：上传图片并保存后，用 /表情 标签 发送；聊天模型也可按语境选择已登记图片。官方QQ与普通QQ均支持本机图片及公开链接。空图库不会猜图或复述收到的图片
- ★ **表情包制作（NoneBot 适配）**：基于你提供的 nonebot-plugin-memes 0.8.1 和 meme-generator 0.2.3
- **表情包库上限**：防止有人一直发表情包把库和磁盘撑爆：按数量上限做 LRU 淘汰、按磁盘配额清理、可屏蔽指定人的表情。只管理机器人实际收藏的表情库和索引
- ★ **表情包管理**：点击“管理表情库”查看缩略图、搜索、上传、修改标签与含义、让AI识图及删除本地收藏。只管理机器人自己的本地库，不同步删除QQ收藏，也不改写核心程序
- ★ **表情包识别记忆**：缓存视觉模型成功识别的单张表情含义，按协议图片标识、完整链接或内联图片指纹复用。只记表情模式需要协议提供表情标记或小图尺寸，普通照片不会凭空被当作表情
- **语音转文字（QQ 原生）**：通过普通 QQ / OneBot 协议端的 fetch_ptt_text 接口转写语音。默认关闭，是否可用取决于当前协议端；失败时明确说明，不能猜测
- ★ **长图分段阅读**：长截图按从上到下分段并留重叠区，由现有视觉模型读取；超出预算或某段失败会明确标注未读

## 消息判定与筛除（5 个）

- **@群友（按名字）**：让机器人用名字 @ 群友：它在正文里写「@泡影之梦 你说得对」时，这里把名字认领成真正的 QQ @ 提醒（对方会收到红点），而不是一串没人看得到的普通字符
- **上下文插话判定**：用一次极短的模型调用判断「这条消息值不值得主动接话」。⚠️ 机制差异：原版在调模型之前判定，判「不接」= 0 token
- **对话完成判定**：同一个人连着发消息时，别在人家话还没说完的时候插嘴。按内容判定：结尾悬着、落在连接词上、或者只有几个字 → 再多等一会儿
- **水聊免回**：连着发表情包、或者一直说水话的时候，机器人就不接了（连模型都不叫醒，0 token）。只认三类明确的水：纯表情/图片、命中水词表（哈哈、草、6、
- **点名闸门**：给机器人加一道点名闸门：① 名单里的群只在被 @ 或戳一戳时才开口（其余消息不调模型）；② 精确到某个群的某个人（名单外的人照常回复）

## 判定与理解（1 个）

- ★ **点名判定**：有人提到机器人名字但没有@时，提示AI考虑是否回应

## 性格细节（2 个）

- **打字错误模拟**：随机在回复中注入打字错误，更像真人
- **每三次表情**：每个会话中，机器人每成功回复N次附带一张真实图库图片。发送失败不计数，已有图片不再追加，避免官方QQ一条回复多图。没有可用图片时只回文字，不伪装成颜文字

## 文风（1 个）

- ★ **引用规范**：提示AI使用「」引号格式而非>引号

## 知识与外号（1 个）

- **群友外号对照**：移植自社区插件 member-aliases：谁在说话就告诉模型这人还叫什么；消息里出现某人的外号时，告诉模型指的是谁 —— 命中才加几行

## 工具与成本（18 个）

- ★ **QQ表情转译**：把 [表情14] 这类数字占位符翻成 [表情:微笑]，让模型读懂 QQ 内置表情。新消息由传输层直接渲染；本插件兜底历史记录与合并转发里的旧格式
- ★ **Token 节流**：移植自社区插件 token-saver，并按本项目的真机数据加强：① 历史滑窗裁剪，更早的内容压成一行摘要（只截取原文，不生成新内容）
- ★ **人设存档隔离**：切换人设后分开对话历史与个人记忆，再切回来可继续原有存档；不会删除或搬走用户文件
- **关键词自动回复**：消息包含关键词时直接返回预设回复，不经过AI
- ★ **图片与表情包识别**：把收到的图片或表情包送给视觉模型识别，再由聊天模型按现有人设回复。每条图片消息增加一次识图调用；沿用现有 API 地址与密钥
- **好感度主动开话题**：按好感度等级排期，到点时按等级概率主动开一句（越高越自然、越不靠频率）
- **定时暖场**：在睡觉时间（默认 23:30~08:00）之外，每隔几小时自动往指定会话发一条符合当前人设的暖场消息；消息由模型现场生成
- **市场探针**：抓取插件市场目录并按关键词筛出相关插件，结果只展示、不自动安装。默认指向 QQ Agent 社区市场（kondius.cn/api/community/pl
- **戳一戳统计**：统计每天被戳一戳的次数；被戳时按概率回复预设文本，并对一个数字执行预设运算后播报结果。普通QQ支持真实戳一戳；官方接入用 /戳一戳 指令
- **提前收尾（省 token）**：移植自 JS 插件 early-finish。已交付完毕、没有遗留动作的这一轮，不再为可选的锦上添花动作多花一次模型调用：跳过“该不该接话”的判定调用和“让
- ★ **搜索词清理与联网查找**：发送 /搜索 关键词，清理口语后读取必应结果并提供带链接的参考；搜索失败明确说明，不编造来源
- **机器人控制台管理**：管理员私聊发送“机器人 状态/连接/队列/日志/人设/插件”直接查询；暂停、恢复回复和重连 QQ 走本地审核。也可以私聊“进入管理员模式”
- **极简模式（省 token）**：移植自社区插件 minimal-mode。按档位砍掉每轮都要重发的聊天记录、给输出封顶、并追加一小段"说短话"的纪律：极简 / 极限 / 敢死三档
- **正在输入提示**：私聊（可选群聊）里让机器人像真人一样亮起「正在输入…」：从它决定要回话到消息发出之间，对方会看到正在输入。零 token：不改提示词、不注册工具、不调模型
- ★ **热梗与热点收集**：每日北京时间6点后采集公开热点，保存来源及时间；/热点 查看缓存，谈到热搜或热梗时提供参考。失败保留有效旧记录并显示更新时间
- **缓存稳定性**：移植自社区插件 cache-stability。把"每轮都会变"的说明排到系统提示词最后，让发送前缀尽量逐字节相同 —— 服务商按前缀缓存计费
- **群友花费统计**：移植自社区插件 group-cost-report：群里 @机器人 说「金额统计」（可跟区间：昨天 / 本周 / 上月 / 最近7天 / 9月1日到9月30
- ★ **长期记忆与群友档案**：记住个人事实与偏好，按会话和发送者隔离。/记住 内容、/记忆 关键词、/忘记 关键词、/我的印象、/群友。自动观察需两次独立消息复证，不能凭模型猜测写入
