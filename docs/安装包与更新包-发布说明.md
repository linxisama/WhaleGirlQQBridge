# 安装包与轻量更新包（发布说明）

本仓库每次发布产出**两件东西**：

| 产物 | 作用 | 生成方式 |
| --- | --- | --- |
| 安装包 `installer/WhaleGirlQQBridge-Setup-<版本>.exe` | 新用户首次安装、跨大版本升级 | `build_installer.ps1` |
| 轻量更新包 `installer/WhaleGirlQQBridge-Update-<版本>.zip` | 老用户小步更新（只装变化的文件） | `tools/build_update.py` |

## 1. 安装包已改为 onedir 布局

`build_installer.ps1` 用 PyInstaller `--onedir` 打包，目录结构为：

```
dist/<版本>/WhaleGirlQQBridge/
  WhaleGirlQQBridge.exe      # 启动器，约 10 MB
  _internal/                 # 依赖、Qt 插件、翻译、源码包、插件资源（约 1200 个文件）
```

安装后 `{app}` 下就是展开的目录结构（`{app}\WhaleGirlQQBridge.exe` + `{app}\_internal\...`），
并额外带 `version.txt` 与随包文档。卸载会一起清掉 `_internal`。

> 为什么不继续用 onefile：onefile 把整个程序压成一个约 78 MB 的 exe，改一行代码也要整包重下，
> 无法做增量更新；onedir 才能让更新包只携带变化的文件。

### 构建命令

```powershell
$env:WHALE_BUILD_PYTHON = 'D:\聊天机器人\qq机器人\.venv-build\Scripts\python.exe'
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_installer.ps1
```

解释器解析顺序：`-Python` 参数 → 环境变量 `WHALE_BUILD_PYTHON` → `<仓库>/.venv-build/Scripts/python.exe`；
都找不到时会抛出中文提示，说明该装什么（`python -m venv .venv-build` +
`pip install -r requirements.gui.txt pyinstaller meme_generator`）。

版本号来自 `src/runtime_identity.py` 的 `APP_VERSION`，不要手改安装包文件名。

## 2. 生成轻量更新包

```powershell
python tools\build_update.py ^
  --old   <上一版 dist 目录，例如 dist\5.2.50\WhaleGirlQQBridge> ^
  --new   <本版 dist 目录，  例如 dist\5.2.51\WhaleGirlQQBridge> ^
  --version 5.2.51 ^
  --out   installer\WhaleGirlQQBridge-Update-5.2.51.zip ^
  --base  5.2.50
```

- 纯标准库，构建机不需要额外依赖。
- 逐文件 sha256 比较，只把**新增或内容变化**的文件放进 `files/`。
- `--base` 省略时默认等于 `--old` 目录的 `version.txt`。

### 包结构

```
WhaleGirlQQBridge-Update-<版本>.zip
  manifest.json          # format/version/base_version/generated_at/files[]/delete[]
  files/<相对路径>        # 仅新增或变化的文件
  apply_update.py        # 随包分发，纯标准库，Windows 友好
  README-更新说明.txt     # 一页纸，给最终用户看
```

## 3. 应用更新

```powershell
# 先预演，不改任何文件
python apply_update.py --target "%LOCALAPPDATA%\Programs\WhaleGirlQQBridge" --dry-run
# 确认无误再真跑
python apply_update.py --target "%LOCALAPPDATA%\Programs\WhaleGirlQQBridge"
```

流程固定为：校验目标目录像安装目录（必须找到 `WhaleGirlQQBridge.exe`）→ 校验包内每个文件的 sha256
→ 备份将被覆盖/删除的文件到 `<安装目录>/.update-backup-<时间戳>/` → 复制/删除 → 复核每个落盘文件的 sha256
→ 任一步失败**自动回滚**并保留备份目录。

退出码：

| 退出码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 1 | 校验/写入失败，已回滚（原文件逐字节复原） |
| 2 | 环境不符（目录不像安装目录、版本基线不符） |

版本基线不符时可用 `--force` 跳过。更新前请先退出程序（安装目录被占用会写入失败，虽然会自动回滚）。

## 4. 边界与注意事项

- **onefile 老安装包不能用更新包**：老用户的 `{app}` 下只有一个 `WhaleGirlQQBridge.exe`，没有 `_internal`，
  更新包校验判定为环境不符（退出码 2）。这类用户必须下载完整安装包，一次性切换到 onedir 布局；之后的版本才能收更新包。
- 更新包是按「某个基线版本」增量生成的，跨多个版本请用对应的安装包，或生成链式包。
- `version.txt` 不参与差分（`build_update.py` 会跳过它），应用成功后会写成新版本号。
- 备份目录默认成功时删除；失败时保留，便于人工核对后重新应用。

## 5. 验收方式

```powershell
python -m unittest discover -s tests -p "test_build_update.py"
```

覆盖：包结构与 manifest、dry-run 不改文件、正向应用后目录逐字节等于新版、delete 清单生效、
manifest sha 被改坏时退出码 1 且目录不变、写入中途失败时回滚且备份保留、非安装目录退出码 2、版本基线门禁。
