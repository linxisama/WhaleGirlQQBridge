# 市场审计：缓存校验与失败恢复

适用于 `tools/audit_external_market.py`，2026-11-05 本轮优化。不安装或运行第三方市场插件。

## 常用命令

```powershell
# 当前市场静态权限扫描，报告放在工作区。
python tools/audit_external_market.py --permissions-only --output-dir .tmp/inv/market-current

# 强制重取公开市场ZIP，不复用已有已验证缓存。
python tools/audit_external_market.py --permissions-only --refresh --output-dir .tmp/inv/market-current

# 同一市场快照和缓存完全离线复算；已有报告时同时核对历史哈希。
python tools/audit_external_market.py --permissions-only --offline --output-dir .tmp/inv/market-current
```

`--offline` 与 `--refresh` 不能同时使用；`--workers` 必须大于0，`--limit` 不得为负数。加 `--limit 10` 仅选择前10条，报告仍分别保留全市场approved分母和本次扫描条数。

## 缓存复用条件

ZIP保存在工作区 `.tmp/external-market/<id>.zip`。在线下载只有在ZIP完整、`<id>.cache.json`中的市场版本/下载地址一致，且SHA256与缓存内容匹配时才直接复用。清单中的id必须是单段安全文件名。

旧版ZIP缓存没有来源元数据，**第一次在线扫描会重新下载一次**并生成元数据，之后才复用；离线扫描仍可读取旧ZIP，并使用已有审计报告中的哈希作验证。`.cache.json`与报告中的哈希是本地一致性证据，不是市场供应商的数字签名。

下载先写入唯一`.part`文件，完整ZIP验证通过后再替换对应ZIP，并记录版本和哈希。网络中断或返回非ZIP内容会重试，最多三次；失败时旧ZIP保留，本次临时文件清理。不会删除其他缓存或改写用户配置。`--refresh`也不会在下载成功前删除旧ZIP。

## 离线复核与报告

离线需要同时保留输出目录的 `market-list.json` 与 `.tmp/external-market/` 中的ZIP；审计报告中的原始权限与哈希不能替代原包。

已有 `external-market-audit.json` 时：

- 清单快照哈希不一致，直接报错退出，原基线报告保留。使用与报告匹配的快照，或选择新的输出目录进行独立批次扫描。
- 对已有历史哈希的条目，核对版本与ZIP SHA256；缺缓存、损坏包或不匹配条目记为失败，不计成“零权限”。
- 包级复核不完整时，新结果写入 `external-market-audit.failed.json` 和 `.failed.md`，退出码1，原基线不覆盖。修复后再次运行，仍对照原基线，不会把失败结果转成可信新基线。
- 成功时更新标准报告。`baseline_verified_packages`是实际与历史基线匹配的包数；首次没有基线时为0，不得称为历史哈希已验证。

`complete=true`表示本次下载/清单读取完整，不代表所有包结构正确、Node语法通过或业务可用。静态权限模式不运行Node，仍需查看每条`problems`、`syntax`和`permissions_only`。
