## 六、本轮修掉的真 bug（摘要）

1. 桥的 `on_prepare` / `on_post_reply` 是同步函数却被 `await` 调用 → 5 个 provider、13 个扩展的返回值被 `except` 吞成「读取附加消息失败」。改异步后这些能力第一次真正生效。
2. `before-tool` / `after-tool` 钩子在`src` 里根本没有调用方 → 现在挂在工具环 `src/tool_loop.py` 上，115 个声明了这两个钩子的扩展才有机会跑。
3. 桥的 payload 只有 `{text,userId,groupId,...}` 六个键，而 0.4 宿主给的是 `{triggerEntries,selfId,persona,messages,session,response,toolName,argsRaw,result,store,memory}` → 扩展读到的全是 `undefined`。现已补齐 11 个契约字段。
4. 扩展 throw 时宿主只回 `no-json (rc=1)`、原始 JS 异常文本丢失 → 已把 stderr 尾部并进错误信息（见 §7 排障口径）。
5. 工具参数 schema 从「一律空对象」变成源码静态提取（不执行 JS）：技能侧 892/1047 工具三者齐备（85.2%），插件侧 271/512 包可提取。
6. 宿主参数位错位：`host-one.mjs` 原本 `tool.execute(payload, {signal,log,metadata})`，与 `execute(ctx, args)` 契约相反 → 修成 `execute(toolCtx, payload)`，两份副本同步，sha256 一致。
7. 安装落点错：市场包原本装到 `<data>/qqagent_extensions`，而 338 个 P3 扩展必须落在 `<宿主根>/plugins/<id>` 才能解析 `../../src/*.js` → 现在统一物化宿主根再装，并立刻探针。
8. 「安装后立即启用」必炸：`update_settings(pid,{'enabled':True})` 撞上「未知设置字段」校验 → 控制字段 `enabled` 现在被识别、校验并保序落盘。
9. plugin.json 必填字段零校验、0 个或多清单被静默忽略 → 现在分级（阻断 vs 提示），提示不再禁用安装按钮。
10. 技能市场四处口径分裂（环境变量、清单来源、层级快照、运行时数据目录）→ 统一同源，界面上的「可注册」才可信。
11. 「装上了」被当成「能跑」：能落盘但加载即抛的扩展包，`enable=true` 仍被登记成启用（回包还自相矛盾地写着「已启用」+「加载探测失败」），留下一条每次调用都失败的白名单 → 三条安装路由统一用 `_enable_after_probe` 判定，探测失败一律按停用登记，落库说明写「宿主加载探测失败：<原因>」。

## 七、已知边界（别读成「全部支持」）

- P4-depends-other 10 个扩展要同宿主里有别的扩展（`host-one.mjs` 一次只装一个），P5-Electron 1 个必然跑不通。
- 231～249 个扩展源码里 `import '../../src/*.js'`，必须落在带 0.4 运行时（`runtime/qqagent-host/`，272 文件 3.9MB）的宿主根里。
- 108 个扩展声明 `web_fetch`，而宿主没有实现 `fetch` → 这些不会真出网。
- 技能侧「放行 ≠ 能用」：`chatKey`/`sender`/`session`/`onebot`/`store`/`kind`/`emit`/`chatId` 这些 ctx 成员宿主还不知道该给什么值，今天一律 `undefined`；静态扫描抓不到别名访问（`const c = ctx; c.chatKey`），所以 21 这个数是上界估计。
- `node:child_process`/`net`/`http`/`https`/`dgram`/`tls`/`worker_threads`/`vm` 8 项默认挡死，包必须在 `skill.json` 的 `permissions` 里声明对应权限才放行（真实市场今天没有任何包声明，通道已用一个包实测验证可放行）。
- 跨进程的「原地修改」在 0.4 契约里本就丢失（159 次实测里 143 次返回 undefined），桥用「返回即权威」兜住能返回的部分，不假装修好。
- 工具环默认关闭（`ai.tool_loop=false`）：开启后每轮可能多一次模型请求，建议先只在主人私聊开。
- 仓库不是 git 仓库；改动前的回滚基线在 `.tmp/snapshots/`。
