# 鲸鱼娘 QQ 控制台操作指南

适用版本：5.2.102 及以后。界面以「鲸鱼娘 QQ 账号版」安装版为准；源码运行的界面相同，数据目录可能不同。

## 1. 启动与确认版本

1. 双击桌面「鲸鱼娘 QQ 账号版」，或从开始菜单打开。
2. 标题栏应显示「鲸鱼娘 · QQ 控制台 5.2.102」。只看到「鲸鱼娘·控制台 5.2.40」说明打开的是旧版，请关闭旧版，改用「鲸鱼娘 QQ 账号版」。
3. 新版默认只允许一个实例。重复双击会把已打开的窗口带到前台。
4. 数据默认在 `%LOCALAPPDATA%\WhaleGirlQQ`。升级不会删除该目录；卸载时只有勾选「删除用户数据」才会清空。

> 旧版和 5.2.99 之后的新版使用不同的安装标识，可以共存。安装器检测到旧版时会在桌面补一个新版快捷方式，但不会自动删除旧版。

## 2. 界面总览

左侧导航分两组：

- 工作空间：对话、智能中心、控制台、对话与记忆、机器人管理
- 管理：人设、插件、设置、外观、外部后端、日志、关于作者

常用入口：

| 想做什么 | 去哪里 |
| --- | --- |
| 改人设、切换当前人设 | 人设 → 选卡片 → 设为当前 |

切换人设后，对话历史与个人记忆按人设分开；切回原人设可继续原有存档，不会删除或搬走用户文件。
| 配 QQ 机器人 | 控制台 → 「QQ 接入」卡片 |
| 给 DSH 登记记忆/机器人工具 | 外部后端 → DSH 联动 |
| 装本地插件 | 插件 → 本地插件包 / 添加插件 |
| 看运行日志 | 日志 |
| 检查更新 | 关于作者 → 自动更新 |

## 3. 首次配置 QQ

1. 在 QQ 开放平台创建机器人，取得 AppID 和 AppSecret。
2. 打开 控制台 → 「QQ 接入」，填入 AppID/AppSecret，保存。
3. 需要沙箱环境时勾选沙箱；正式环境按平台要求配置 IP 白名单。
4. 点「启动」，状态变为运行中后，在 QQ 里私聊或 @ 机器人测试。
5. 机器人没有回复时，先看「日志」页的错误，再检查：
   - AppID/AppSecret 是否填错；
   - 机器人是否已启动；
   - 当前账号是否在目标群/私聊白名单；
   - 模型 API 是否配置且余额可用。

## 4. 接入 DSH（DeepSeek Harness）

### 4.1 源码版

打开 外部后端 → DSH 联动。源码运行时程序知道自己的仓库位置，直接点「接入当前 DSH」即可。

### 4.2 安装版

安装版不含 Python 源码，必须告诉它仓库在哪：

1. 在「源码仓库根」填含 `tools\` 和 `src\` 的那一层，例如 `D:\qq机器人5.0`。
2. 点「接入当前 DSH」。成功后显示 profile、三组 MCP 条目和使用的 Python。
3. 填过一次会记住，下次自动带出。也可以设环境变量 `WHALE_QQ_REPO`。
4. 如果提示 `dsh_needs_source`，说明路径不对或那台电脑没有源码仓库；安装版不能把安装目录当源码仓库。

### 4.3 连接体检

DSH 联动区点「连接体检」，会显示：

- 三组工具是否登记齐全；
- 当前 profile 的 yaml 是否用了当前版本的命令；
- 是否需要重启 DSH；
- 新会话是否可用；
- 缺什么、下一步怎么做。

看到「需要重启 DSH」时，完全退出 DSH 再打开，新建会话后才会出现 `mcp__whale_memory__*`、`mcp__whale_bot__*`、`mcp__whale_tools__*`。

### 4.4 多 profile

程序会扫描 `DSH_HOME\profiles` 下的真实 profile，逐个接入；某个 profile 的 yaml 坏了只影响它自己，不会拖垮其他 profile。重复点接入是幂等的，不会反复改文件。

## 5. 插件

### 5.1 在线插件市场

插件 → 插件市场，选插件 → 安装。安装后可启用/停用。市场插件第一次安装会创建目录，重复安装会复用已有目录，不会覆盖你改过的配置。

### 5.2 本地插件包

插件 → 本地插件包：

1. 列表显示 `plugin_packages` 里可安装的包（名称、版本、说明、状态）；已安装的包会标注「已安装」。
2. 选中后点「安装到本地插件目录」；勾选「安装后自动启用」可同时启用，不勾则按包内默认值（通常是停用）。
3. 已安装的包再次安装会提示；需要覆盖时勾选「覆盖已安装」。
4. 安装完成后回到插件列表，可随时启用/停用；不需要时点删除，目录包会连目录一起移除。

### 5.3 手动安装与目录说明

- 插件包源目录：`<程序目录>\plugin_packages\<插件id>\`，含 `plugin.json`、`README.md`、入口 `.py`。
- 用户插件目录：`%LOCALAPPDATA%\WhaleGirlQQ\data\qq-only\custom_plugins\<插件id>\`（以 `GET /api/plugins/custom` 返回的 `dir` 为准；源码运行时在仓库的 `data\qq-only\custom_plugins`）。
- 只加载用户手动放入或明确点安装的插件，不会自动安装。
- 停用不会删文件；移除请先停用，再删除对应目录。
- 插件异常只影响该插件，控制台会显示中文错误，不会让整个程序退出。

### 5.4 目录式插件内核（plugin_core）

插件 → 内核插件：这里管理带 `plugin.json` 的目录式插件，和上面的单文件插件是两套互不影响的加载器。

1. 点「选择目录…」或「选择 zip…」，指向一个插件目录（目录里直接有 `plugin.json`，或 zip 里只有一个这样的顶层目录）。
2. 点「安装」。安装只复制到当前账号的数据目录，不上传、不改内置插件；勾选「覆盖已安装的同名插件」才会替换旧版本。
3. 安装成功后内核会自动重载；列表里能看到插件名、id、版本。选中后点「移除选中」即可卸载。
4. 目录位置：`%LOCALAPPDATA%\WhaleGirlQQ\data\qq-only\plugin_core\plugins\<插件id>\`（源码运行时在仓库的 `data\qq-only\plugin_core\plugins`）。

插件格式与 API 见仓库根目录 `plugin_core/README.md` 和 `docs/插件内核-API-v1.md`。

### 5.5 插件需要本地文件

插件配置里的文件字段会显示「选择文件/选择文件夹」按钮。选中的文件会复制到 `%LOCALAPPDATA%\WhaleGirlQQ\data\plugin_uploads`，之后即使原文件移动也能用；不会自动上传到公网。

## 6. 自动更新

1. 关于作者 → 自动更新，填仓库 `linxisama/WhaleGirlQQBridge`（或完整 GitHub 链接），保存。
2. 启动 12 秒后自动检查一次；也可以点「检查更新」。
3. 有新版本时显示版本号、发布时间和完整更新说明；点「一键更新」。
4. 下载时显示进度、速度和阶段；下载完校验 SHA256，校验不过不会安装。
5. 安装器在程序退出后接管，完成后自动重新打开。失败会保留日志：`%TEMP%\WhaleGirlQQBridge-updates\update-<pid>.log`。
6. 没有网络、包损坏、安装失败时都可以重试；已下载的文件会重新校验。
7. 源码运行不能一键覆盖，请用安装版更新。

## 7. 数据、备份与迁移

- 数据目录：`%LOCALAPPDATA%\WhaleGirlQQ`。
- 升级前建议备份整个目录；至少备份 `data\` 和 `config.qq.yaml`（如果存在）。
- 换电脑：先在新电脑安装同版本，退出程序，把旧电脑的数据目录复制到新电脑相同位置，再启动。
- DSH 仓库路径是每台电脑独立的，换电脑后要重新填「源码仓库根」。
- 卸载默认保留用户数据；要彻底清理，卸载时勾选删除数据，或手动删除 `%LOCALAPPDATA%\WhaleGirlQQ`。

## 8. 常见问题

**打开的是旧版 5.2.40？**  
旧版是独立程序，升级新版不会覆盖。关闭旧版，从「鲸鱼娘 QQ 账号版」启动；不要从旧网关的旧账号点「连接机器人」。

**DSH 显示未就绪、缺 host-one.mjs？**  
5.2.94 起安装包已带 `runtime\qqagent-host`。仍报缺时，确认安装目录 `_internal\runtime\qqagent-host\host-one.mjs` 存在；没有就重装当前版本。

**连接体检说需要重启 DSH？**  
完全退出 DSH（包括托盘/后台进程）再打开，新建会话。只重开窗口不算重启。

**插件装了但工具没出现？**  
确认插件已启用、能力桥 ready、DSH 新会话已创建；在连接体检里看三组 MCP 是否登记齐全。

**更新卡在下载？**  
看进度文字和 `%TEMP%\WhaleGirlQQBridge-updates` 日志；网络恢复后重试。校验失败会拒绝安装，不会留下半成品。

**端口被占用/后台版本不一致？**  
关闭所有旧控制台和旧后台进程，再从当前安装版启动。新版默认端口 27499，旧版是 8090。

## 9. 回滚

1. 保留上一版安装包和更新包。
2. 退出程序，运行旧版安装包覆盖安装；用户数据默认保留。
3. 如果新版本改过 DSH yaml，连接体检会提示重启；需要时用 `config_changed_at` 之前的备份恢复（程序写 yaml 前会自动生成 `.bak-whale-memory-*`）。
4. 卸载重装不会删除 `%LOCALAPPDATA%\WhaleGirlQQ`，除非手动勾选删除。
