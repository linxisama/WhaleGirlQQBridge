## 复现

标准库Python，无新增依赖：

```powershell
# 在线获取当时市场快照、ZIP与权限证据；未来清单会变化。
python tools/audit_external_market.py --permissions-only --output-dir .tmp/inv/market-20261105 --workers 8

# 同一份market-list.json及ZIP存在时，完全离线复算；不访问市场。
python tools/audit_external_market.py --offline --permissions-only --output-dir .tmp/inv/market-20261105 --workers 8
```

原始产物：`.tmp/inv/market-20261105/market-list.json`、`external-market-audit.json`、`external-market-audit.md`，ZIP在`.tmp/external-market/`。本次报告JSON已另存`docs/`，避免清理临时目录后连计数依据也丢失。离线重新读取ZIP需要同时保留清单快照和缓存；仅保留汇总不能重新验证原包哈希。

不依赖缓存、从持久JSON重算计数：

```powershell
python -c "import json,collections; d=json.load(open('docs/插件市场权限审计-20261105.json',encoding='utf-8')); a=[r for r in d['items'] if r['permissions_array']]; print(len(d['items']),len(a),sum('web_fetch' in r['permissions'] for r in a)); print(dict(sorted(collections.Counter(w for r in a for w in r['permissions'] if isinstance(w,str)).items())))"
```

加载批测是另一任务：先用审计工具下载当前approved包到`.tmp/external-market/`，才能执行`python tools/sweep_market_extensions.py --copy`。输出`.tmp/inv/sweep-report.json`、`.tmp/inv/sweep-report.md`（`tools/sweep_market_extensions.py:34-39`）。本次没有执行批测，不能重申旧510/512或511/512为当前结果。

## 功能改动与验收

`tools/audit_external_market.py`新增：

- `--output-dir`：报告写入调用方指定目录，本轮只写工作区，不覆盖外部市场物料。
- `--permissions-only`：跳过Node语法检查，只读清单；不执行第三方插件代码。
- `--offline`：使用同一清单快照与缓存ZIP重算，缓存缺失记录明确错误。
- 持久化清单快照、逐包权限类型/原数组、ZIP哈希、manifest位置；汇总权限数组数、含web_fetch包数、全部词频、下载失败和不可读清单数。
- 无manifest时不再索引空列表；损坏manifest不再被当作空对象成功读取。下载失败或清单不可读返回1，避免以不完整统计冒充完成；`--limit`不再改变全市场approved分母。Node语法检查加20秒超时。

专项测试覆盖：权限数组/非数组、重复权限计数、无JS仍保留清单证据、无manifest、损坏ZIP/JSON、离线缺缓存、limit分母。命令：`python -m unittest tests.test_audit_external_market -q`，8项通过（0.118秒）。在线扫描和离线复算均返回818/474/157，缺失和不可读为0。附加运行的现有registry/host批次长时间无输出，已中止，不计入通过；本次不修改这些运行时模块，不宣称它们完成回归。
