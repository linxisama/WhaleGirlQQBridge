# 插件规格 v1（冻结版）

**本规格冻结什么**：从本版起，本仓库认的"包"只有 5 类，这 5 类的**清单文件名、字段、入口形态、能用的 api、生命周期**一律按本文执行，不得再改；工具接口以 **MCP（stdio JSON-RPC，protocolVersion `2025-06-18`）** 为通用层——我们既作为 MCP server 对外暴露本机工具面（`tools/whale_tools_mcp.py`，serverName `whale_tools`），也把外部 `mcp.json` 当作第五类包导入。写操作（既有 DANGEROUS 集合 ∪ workspace 写 ∪ `pc_*` 非只读）必须 `confirm:true` 且全量落审计，只读工具默认放开。本文所有"规则"都带 `文件:行号` 证据，证据不足的写"待定，见附录 B"。真装/真调/真协议往返的实测输出见附录 A，取证脚本在 `.tmp/inv/spec-evidence/run_evidence.py`。

## §2 清单校验规则

### 2.1 公共字段约束

| 字段 | 类型/取值 | 约束与失败表现 | 出处 |
| --- | --- | --- | --- |
| 清单大小 | — | 宿主读清单 >256KB → `manifest-unsafe`；`plugin.json` >64KB → blocking "过大（上限 64KB）"；`pack.json` >64KB → "过大" | `host-one.mjs:69-92`、`plugin_installer.py:642-711`、`feature_pack.py:79-95` |
| `capabilities` / `requires` | 非空字符串数组，**≤128 项**，去重 | 违反 → `manifest-invalid`："<id>.<key> 必须是非空能力名数组" | `host-one.mjs:84-90`（上限在 :86） |
| `id` | 四处口径不同，见 2.2 | 不过正则即拒 | 见 2.2 |
| `version` | 整数＝**格式版本**；产品版本是 `app_version` | 整数 version 不被当成产品版本 | `pack_import.py:642-649`、`plugin_installer.py:550` |
| `enabledByDefault` | 布尔；字符串按 `^(false|0|no|off)$` 取反；数字 !==0 | 缺失/非布尔按 true | `plugin-loader.js:168-179`、`skills/manifest.js:66-116` |
| `category` | `model/message/knowledge/media/utility` | 非法回退 `utility` 并记 problem | `skills/manifest.js:49` |
| `apiVersion` | 数字，当前支持 1 | >1 记 problem "apiVersion N 高于当前支持的 1" | `skills/manifest.js:66-116` |
| `prompt.sections[].priority` | 数字，钳在 `min(99, …)` | 技能不能压过核心安全规则 | `skills/manifest.js:119-136` |

### 2.2 每家族专属校验点

| 家族 | id 正则（出处） | 其余硬校验 |
| --- | --- | --- |
| 宿主读清单 | `^[a-z0-9][a-z0-9._-]{0,63}$`（`host-one.mjs:11`） | 清单只认 `skill.json`/`plugin.json`；符号链接清单或 >256KB 拒（`host-one.mjs:69-92`） |
| 扩展安装（zip） | `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$`，**不含下划线**（`qqagent_host.py:59`） | 4000 文件 / 24MB / 路径越界 / 符号链接全拒（`qqagent_host.py:752-844`） |
| plugin-py | `^[a-z][a-z0-9_]{1,47}$`，**小写+下划线**（`plugin_installer.py:44`） | 源码必须引用 `PluginBase` 与 `PluginMeta`；AST 抓危险调用（`plugin_installer.py:156-177`） |
| mcp-server | `^[A-Za-z0-9][A-Za-z0-9_.-]{0,63}$`（`pack_import.py:67`） | 没有 `command`（只有 url/type）→ `unsupported-transport`；command 非绝对路径 → `command-not-absolute`（`pack_import.py:740-783`） |
| skill / feature-pack | skill `^[A-Za-z0-9_-]{1,60}$`（`agent_learning.py:296-328`） | `version` 必须 `type is int` 且 ==1；`permissions` 只能取 8 个白名单值（`agent_learning.py:44-46`） |

### 2.3 老方言归一（B1）

| 老写法 | 归一结果 | 出处 |
| --- | --- | --- |
| 整数 `version`（格式版本）+ `app_version`（产品版本）+ 无 `entry` | 产品版本取 `app_version`；入口按包内唯一 `.py` 补全；记 notice `b1-dialect-normalized` | `pack_import.py:803-821`、`plugin_installer.py:557-565,598-639` |
| `plugin.json` 无 `apiVersion` 但 entry 是 `.js/.mjs` 或有 `index.js` | 判为 extension-js（方言 `qqagent-0.4`） | `pack_import.py:242-323` |
| 裸单文件 `.py`（无清单） | plugin-py，置信 0.72 + notice `no-manifest` | `pack_import.py:242-323` |
| `plugin.json` 的 `prompt:{when,examples,instruction}` | 适配成 `prompt.sections`（section id `legacy`，priority 50） | `plugin-loader.js:49-65` |

## §3 工具定义规格

| 字段 | 必填 | 取值 | 默认 | 出处 |
| --- | --- | --- | --- | --- |
| `id` | 是 | `^[a-zA-Z0-9_-]{1,64}$` | — | `tool-registry.js:35-42` |
| `name` | 是 | 非空字符串（给人看的） | — | `tool-registry.js:35-37` |
| `description` | 建议 | 模型据此决定何时调；写清"什么时候用" | `''` | `tool-registry.js:4-14` |
| `category` | 否 | 8 类之一 `messaging/sticker/query/memory/web/knowledge/media/system` | `system` | `tool-registry.js:43-56,235-244` |
| `icon` | 否 | 单字符 emoji | `🔧` | `tool-registry.js:43-56` |
| `defaultEnabled` | 否 | 布尔 | `true` | `tool-registry.js:43-56` |
| `requiresVision` / `requiresSearch` | 否 | 布尔；缺能力时该工具在可用性判定里被关 | `false` | `tool-registry.js:126-212` |
| `parameters` | 是 | JSON Schema（`type/properties/required/additionalProperties`），对外同时以 `inputSchema` 暴露 | — | `host-one.mjs:295-296` |
| `execute` | 是 | `(ctx, args) => ({content, isError})`，非函数直接拒 | — | `tool-registry.js:35-37` |

**id 拼接规则**（`plugin-loader.js:80-93`）：注册进模型工具表时一律变成 `<skillId>__<tool>`；skillId 先 `replace(/[^a-zA-Z0-9_-]/g,'_')` 再截 24 字，tool 截 38 字，总长 ≤64；已带前缀的不重复加；跨 Skill 撞名时后加载者覆盖先加载者并 `console.warn`。

**返回值契约**：`{content:[{type:'text',text:'…'}], isError:boolean}`（`tool-registry.js:4-14`）。`isError:true` 表示"执行了但失败"，不是"没执行"。

正确样例见 §1(1)；错误样例与真实报错文案：

| 错误写法 | 结果（真实文案） | 出处 |
| --- | --- | --- |
| 缺 `id` | 抛 `工具必须提供 id` | `tool-registry.js:35-37` |
| 缺 `name` | 抛 `工具 <id> 必须提供 name` | `tool-registry.js:35-37` |
| `id:"我的工具"` | 抛 `工具 id 不符合 OpenAI 函数名规范 [a-zA-Z0-9_-]{1,64}：我的工具` | `tool-registry.js:40-42` |
| 缺 `execute` | 抛 `工具 <id> 必须提供 execute 函数` | `tool-registry.js:35-37` |
| `module.exports = {…}`（CJS） | 加载失败 `cjs-unsupported`："把 module.exports 改成 export async function setup(api)" | `plugin-loader.js:412` |
| entry 在目录外/符号链接越界 | "entry 必须是 Skill 目录内的相对路径：X" | `plugin-loader.js:349-372` |

## §4 事件钩子规格（Python 插件）

全部定义在 `PluginBase` 上、默认空实现，按需覆盖（`src/plugins/__init__.py:94-140`）。

| # | 钩子 | 签名 | 触发时机 | 允许 | 禁止 |
| --- | --- | --- | --- | --- | --- |
| 1 | `on_ingest` | `(message: dict, runtime) -> Optional[str]` | 消息入队时 | 返回 str ＝ 立刻回复并**跳过 AI**；None ＝ 继续 | 阻塞 IO、调用模型 |
| 2 | `on_block` | `(message, runtime) -> bool` | 入队前 | 返回 True ＝ 静默丢弃这条 | 在返回值里表达"回复" |
| 3 | `wants_reply` | `(message, runtime) -> bool` | 入队前（未 @ 的群消息靠它进 AI） | 返回 True ＝ 让这条进入 AI | 假设每条都会被 @ 触发 |
| 4 | `on_pre_ai` | `(message, conversation: list, runtime) -> Optional[dict]` | 调模型前 | 返回 `{delay,block,extra_system,volatile_system,max_tokens}` | 改 conversation 里的历史 |
| 5 | `volatile_hint` | `(runtime, text) -> Optional[dict]` | 拼系统提示词时 | 返回 `{volatile_system}` 或 `{extra_system}`；装 `cache_stability` 且开 `stableOrder` 时排到提示词最后（吃前缀缓存） | 返回大段稳定文本（会毁缓存） |
| 6 | `validate_settings` | `(settings: dict) -> None` | 配置窗保存前（schema 校验之后） | 抛异常＝拒绝保存并显示原因 | 静默改值 |
| 7 | `on_prepare` | `async (message, runtime) -> None` | 构造模型对话前 | 预查数据、写 runtime | 长耗时（拖慢首字） |
| 8 | `on_sent` | `(message, reply, runtime) -> None` | 发送**成功后** | 统计、落盘 | 假设"调用了就一定成功" |
| 9 | `on_post_reply` | `async (message, reply, runtime) -> str` | 最终回复串发出前 | 变换文本（发送节奏用） | 返回 None（契约是 str） |

**两个生命周期节点（不是事件）**

| 节点 | 语义 | 允许/禁止 | 出处 |
| --- | --- | --- | --- |
| `post_load(self)` | 实例**已被管理器注册之后**调用一次 | 需要落盘改设置只能放这里；`__init__` 里调 `update_settings` 会 `KeyError: Unknown plugin` | `plugins/__init__.py:140`、`manager.py:406-457` |
| `tick(self, runtime)`（async） | 机器人运行中约每 60s 一次 | 单插件异常被收成失败记录，不打断整轮；**串行 await**，别在里面睡 | `manager.py:872-883` |

## §5 配置规格

`FieldSchema` 字段全集（`src/plugins/__init__.py:9-24`，序列化口径 `:37-60`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `type` | str | 决定控件，见下 |
| `label` | str | 显示名（必填） |
| `description` | str | 提示文本；文件字段显示在按钮右侧 |
| `group` | str | 分组标题 |
| `values` / `options` | List[str] / List[dict] | 下拉候选（`options` 可带 label/value） |
| `min/max/step` | float? | 数字框范围与步长 |
| `multiline` | bool | 多行文本框 |
| `file_picker` | str | `file`(单文件) / `files`(多文件) / `labeled_files`(带标签表) / `directory`(选文件夹) |
| `file_extensions` | List[str] | 每项须 `^\.[a-z0-9]{1,10}$`，否则 "插件文件类型配置无效" |
| `file_max_mb` | int | 默认 6，须 1..256，否则 "插件单文件上限须为1–256MB" |
| `editor` | str | `pc_owner`(只读) / `keyword_rules`(专用编辑器) |

`type` → 控件映射（`qq_gui.py:3002-3210`）：`bool`→复选框；`select`→下拉；`int/float`→数字框；`text`、`multiline`、`file_picker` 为 `files/labeled_files`→多行；其余→单行。

**上传规则**（`src/plugin_files.py` + `qq_gui.py`）：按钮文案按 `file_picker` 与扩展名自动生成（"选择文件夹…"/"上传图片…"/"上传文件…"，`qq_gui.py:2952-2974`）；一次 1–20 个文件，`file` 恰好 1 个；单文件 ≤`file_max_mb`、总量 `min(max(64MB, 上限*min(个,20)), 1024MB)`；图片按文件头校验（读 ≤8MB）；**落盘** `data/plugin_uploads/<插件id>/<字段名>/<sha256+扩展名>`（`qq_gui.py:2993`），写入走 `uuid.tmp` 边复制边校验（"复制过程中被改动，请重新选择"）；合并口径见 `plugin_files.py:128+`（`file` 取首项路径；表格式按行合并，`#` 开头为注释）。

## §6 能力（capability）规格

| 动作 | 写法 | 出处 |
| --- | --- | --- |
| 声明提供 | 清单 `capabilities:["sticker.source"]` + 代码里同名函数/对象；**只在清单写、没有实现** → `dependency-unimplemented` | `host-one.mjs:157-186`、`skills/capabilities.js:13-34` |
| 声明依赖 | 清单 `requires:[…]`；自依赖（同一名字同时出现在两处）被静默剔除 | `skills/manifest.js:94-95` |
| 软取用 | `api.capability(name, args)` 取第一个生效提供者，异常吞掉返回 `undefined`；`api.hasCapability(name)` 先问有没有 | `plugin-loader.js:109-114` |
| 同名多提供者 | `providersOf` 按注册顺序返回全部；消费方取第一个生效者；**只有依赖判定**阶段多提供者才算错 | `skills/capabilities.js:13-34` |
| 同 owner 重复注册 | 覆盖不叠加 | `skills/capabilities.js:28-31` |

| 错误码 | 判定条件 | 文案模板 | 出处 |
| --- | --- | --- | --- |
| `dependency-missing` | 启用闭包里没有任何扩展提供该能力 | "<id> 缺少已安装的能力提供者：<cap>" | `host-one.mjs:157-186` |
| `dependency-disabled` | 有能力提供者但都没启用 | "<id> 的依赖未启用：<cap>（a, b）" | 同上 |
| `dependency-ambiguous` | 同一能力有 ≥2 个**已启用**提供者 | "<id> 的能力有多个已启用提供者：<cap>（a, b）" | 同上 |
| `dependency-cycle` | 依赖闭包成环 | "依赖环：a -> b -> a" | 同上 |

## §7 MCP 规格（通用层）

**角色**：① 我们是 server（`tools/whale_tools_mcp.py`，serverName `whale_tools`，固定三工具 `tools_list/tools_call/tools_status`，`:94-115`）；② 我们是 client（`src/mcp_client.py`，protocolVersion `2025-06-18`，clientName `whale-agent`，`:21-23`）。

| 必须支持的方法 | 方向 | 说明 | 出处 |
| --- | --- | --- | --- |
| `initialize` | 双向 | 回/发 protocolVersion、capabilities、serverInfo、可选 instructions | `whale_tools_mcp.py:414-453`、`mcp_client.py:171-251` |
| `notifications/initialized` | 双向 | 收到不回；client 握手成功后主动发 | 同上 |
| `ping` | 双向 | 回 `{}` | `whale_tools_mcp.py:414-453` |
| `tools/list` | 双向 | 每项只保留 name/description/inputSchema | `mcp_client.py:314-329` |
| `tools/call` | 双向 | 回 `{content:[…], isError}`，isError 原样透传 | `mcp_client.py:331-355` |
| 未知方法（带 id） | 双向 | 回 `{error:{code:-32601,message:"Unsupported method: X"}}` | `whale_tools_mcp.py:414-453` |

**写工具标记**：`is_write(id)` 认两种写法（`whale_tools_mcp.py:54-91`）——`<extId>__<toolId>` 或裸 toolId 命中 `WRITE_TOOLS`（DANGEROUS 六件套 `service/open_path/open_url/type_text/hotkey/screenshot` + `workspace__write/append`）；`pc_` 前缀除 `pc_status/pc_active_window/pc_clipboard_read` 三个只读外全算写。实测真值表：`workspace__write→true、workspace__append→true、pc_click→true、type_text→true、screenshot→true、pc_status→false、csgo-5e__team_roster→false`。

**缺 `confirm` 的返回形状**（实测）：不执行，`isError:true`，payload `{"ok":false,"write":true,"confirm":false,"error":{"code":"confirm-required","message":"该工具会改动机器，需外部客户端确认后带 confirm:true"}}`（`whale_tools_mcp.py:377-402`）。外部 MCP server 必须实现同一形状（§1(5) 的样例 server 已实测同形状）。

**审计行字段**（每次 `tools_call` 追加一行，`whale_tools_mcp.py:274-291`）：`{ts, tool, write, confirm, ok, code, duration_ms, client}`，落 `<data_dir>/qq-only/mcp_tool_calls.jsonl`，超 8MB 轮转为 `mcp_tool_calls.previous.jsonl`；写审计失败只让 `audited:false`，绝不让调用失败。

**超时与退出**：client 默认 20s（`mcp_client.py:142-151`），错误码 `spawn-failed/handshake-timeout/handshake-failed/not-running/timeout/server-error/bad-json/io/internal`（`:34-36`）；超时先 `taskkill /T /F` 收进程树（防 `.cmd` 垫片留孤儿，`:84-105`）；server 侧单工具超时 60s（`whale_tools_mcp.py:41`）；对端非 JSON 行计 `bad-json` 后继续读，上限 20 行。

## §10 写新插件的 10 分钟上手

**(a) 注册一个只读工具的 JS 扩展**：直接抄 §1(1) 两个文件，落 `<host_root>/plugins/spec-demo-js/`，`import_probe` 里应出现工具 id `spec-demo-js__greet`（实测见附录 A/a）。

**(b) 带事件钩子的 Python 插件**（骨架同 §1(2)，钩子写法如下）：

```python
class SpecDemoPlugin(PluginBase):
    META = PluginMeta(id="spec_demo_py", name="规格样例：事件钩子插件",
                      description="计数+拦截+注入", category="utility", enabled_by_default=True,
                      config_schema={"greeting": FieldSchema(type="string", label="问候语"),
                                     "keywords": FieldSchema(type="text", label="拦截关键词",
                                                             multiline=True)},
                      default_settings={"greeting": "收到", "keywords": ""})

    def post_load(self):                       # 实例已注册，这里才允许改设置
        self.count = int(self.load_state("count.json", {}).get("n") or 0)

    def on_ingest(self, message, runtime):     # 命中关键词就抢答
        words = [w.strip() for w in str(self.get("keywords") or "").splitlines() if w.strip()]
        if any(w in str(message.get("text") or "") for w in words):
            return str(self.get("greeting") or "收到")
        return None

    def wants_reply(self, message, runtime):   # 未 @ 的群消息是否进 AI
        return False

    def volatile_hint(self, runtime, text):    # 每轮刷新的动态片段
        return {"volatile_system": "当前已处理 %d 条消息。" % self.count}

    def on_sent(self, message, reply, runtime):
        self.count += 1
        self.save_state("count.json", {"n": self.count})

    async def tick(self, runtime):             # 约 60s 一次
        self.save_state("count.json", {"n": self.count})
```

**(c) 外部 MCP 服务器 + `mcp.json`**（完整可跑版见 `.tmp/inv/spec-evidence/sample_mcp_server.py`，实测见附录 A/c）：

```python
PROTOCOL_VERSION = "2025-06-18"
SERVER_NAME = "spec-demo-mcp"
TOOLS = [{"name": "echo", "description": "回显",
          "inputSchema": {"type": "object", "properties": {"text": {"type": "string"}}, "required": ["text"]}},
         {"name": "write_note", "description": "写一条笔记",
          "inputSchema": {"type": "object", "properties": {"text": {"type": "string"}}, "required": ["text"]}}]
WRITE = {"write_note"}

def handle(msg):                                   # 逐行 stdin → 一行 stdout
    mid, method = msg.get("id"), msg.get("method")
    if method == "initialize":
        return {"jsonrpc": "2.0", "id": mid, "result": {
            "protocolVersion": PROTOCOL_VERSION, "capabilities": {"tools": {"listChanged": False}},
            "serverInfo": {"name": SERVER_NAME, "version": "1.0.0"}}}
    if method == "tools/list":
        return {"jsonrpc": "2.0", "id": mid, "result": {"tools": TOOLS}}
    if method == "tools/call":
        name = msg["params"]["name"]; args = msg["params"].get("arguments") or {}
        if name in WRITE and not args.get("confirm"):
            body = {"ok": False, "write": True, "confirm": False,
                    "error": {"code": "confirm-required", "message": "写工具需 confirm:true"}}
            return {"jsonrpc": "2.0", "id": mid, "result": {
                "content": [{"type": "text", "text": json.dumps(body, ensure_ascii=False)}],
                "isError": True}}
        body = {"ok": True, "echo": str(args.get("text") or "")}
        return {"jsonrpc": "2.0", "id": mid, "result": {
            "content": [{"type": "text", "text": json.dumps(body, ensure_ascii=False)}], "isError": False}}
    if mid is not None:
        return {"jsonrpc": "2.0", "id": mid,
                "error": {"code": -32601, "message": "Unsupported method: %s" % method}}
    return None
```
