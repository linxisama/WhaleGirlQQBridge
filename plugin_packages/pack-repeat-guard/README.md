# 复读闸门（pack-repeat-guard 1.0.0）

## 来源
从内置插件 `src/plugins/anti_repeat.py`（「打断复读」）独立出来的自包含目录 mod。判定口径
保持一致：按 `(房间, 文本)` 计数，窗口内超过 `max_repeat` 次就丢弃；带图片的消息把 `media`
的哈希并进键里，避免把不同的图当成同一句复读。**内置文件没有改动**，两者可以并存。

## 能力
- 钩子：`on_block(message, runtime)`，入队前拦截，返回 `True` 表示这条静默丢弃。
- 只读 `message` 字典与自己的设置；不发送任何消息，不碰 bot/db/网络。
- 需要权限：`read_message`（只声明，用于审计与展示）。

## 依赖
- 宿主：WhaleGirlQQ ≥ 5.2.0（目录 mod 支持 `api_version: 1`）。
- 外部依赖：无。只用标准库 `hashlib` / `json` / `time`。

## 配置
| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | `false` | 总开关；挂上后默认不生效 |
| `max_repeat` | int | `3` | 窗口内允许的出现次数，超过即丢弃 |
| `window_sec` | int | `60` | 统计窗口（秒） |

## 示例配置
同目录的 `config.example.json` 展示了可用的设置键和默认值，仅供对照；实际配置以控制台插件页保存的值为准。

## 安装 / 停用 / 移除
见上级目录 `README.md`「手动添加的稳定插件包」。要点：整目录复制进自定义插件目录，
目录名必须是 `pack-repeat-guard`；停用只需关 `enabled`；移除就删目录。

## 已知限制
- 计数只在内存里，进程重启后清零（内置同类插件也一样）。
- 只统计群聊；私聊不拦。
- 判定窗口是滑动窗口，密集刷屏时旧记录会被提前挤掉。
