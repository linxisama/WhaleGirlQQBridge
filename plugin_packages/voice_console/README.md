# 语音控制台插件 1.0.2

适用：鲸鱼娘 QQBridge **5.1.2 及以上、包含音频网关的版本**。这是当前控制台功能的插件入口，不是模型安装包，也不能通过安装此插件把旧版宿主升级到 5.1.2。

## 安装

1. 在原生控制台进入「能力与插件」，选择从本地文件安装。
2. 选择插件市场目录提供的「语音控制台-1.0.2.zip」，查看预检结果后安装。也可选择本目录的 `voice_console.py`。宿主安装器只部署该单文件，不会自动安装本包说明或额外核心模块。
3. 打开「语音控制台」配置，填写允许使用的主人 QQ 号（多个用逗号分隔），保存并开启插件。默认关闭、主人列表为空、群聊和普通回复转语音均关闭。
4. 自行启动已有本地 TTS 服务。插件不会启动程序、安装依赖或下载模型，也不调用云端收费 API。

把插件放在“插件市场”目录不会自动安装或启用它，本次交付没有修改实际运行实例的插件清单和配置。

## 配置与操作

可以继续使用宿主「音频与语音」页配置、生成和试听；插件任务也显示在此页。

也可以在插件配置窗选择 audio.cpp / GPT-SoVITS / Qwen，填写对应端点、模型和音色。默认端点分别为 18100、9880、7860；只接受本机地址。Qwen 模型类型必须与模式相符，且模型应事先准备好；描述式音色填写「Qwen音色/语气描述」，固定说话人模式也可用它填写语气要求。

GPT-SoVITS 与 Qwen 克隆需要的参考音频请点「上传参考音频」，填写准确台词。原生窗按 FieldSchema.file_picker 生成按钮，复制到宿主运行数据目录 `data/plugin_uploads`，不依赖原文件继续存在，也不上传公网。参考音频最大 8MB，支持 WAV/FLAC/MP3；不要手填数据目录外的文件路径。

插件设置保存后**不会自动改写宿主引擎**。主人在原始私聊发送 `语音 应用配置` 才会增量应用所选引擎和本地路由到共享音频网关；其效果也会体现在宿主音频页。已有音频任务未结束时不能应用。不会替换 QQ 账号、聊天 API、人设、其他插件或云凭据。

| 指令 | 作用 |
|---|---|
| `语音 帮助` | 查看操作说明 |
| `语音 状态` | 查看共享网关当前引擎；不是实时服务探测 |
| `语音 检测` | 只读检测插件表单中所选本机接口，不保存配置、不生成音频 |
| `语音 应用配置` | 仅主人原始私聊可显式应用配置 |
| `语音 朗读 你好，我在这里。` | 提交 TTS；回执文本成功发送后尝试将语音发回原会话 |
| `语音 任务 <完整24位编号>` | 查询本人在当前账号与会话的生成状态与QQ交付回执；重载插件后仍可查询 |
| `语音 取消 <完整24位编号>` | 取消本人的排队或生成中任务；不能撤回已生成音频或已提交给QQ的发送请求 |
| `语音 电脑状态` | 主人私聊查询配对数与急停状态，不执行电脑动作 |
| `语音 急停` | 主人私聊请求宿主 Agent 急停；批准和恢复仍须在本机控制台操作 |

群聊要同时开启插件「允许主人在群里朗读」、通过宿主现有回复规则并由主人发送明确指令。引用、转发不触发这些操作。所有功能继续受宿主登录状态、账号与目标权限限制。

如开启「主人聊天回复同时转语音」，主人原始会话的文字回复成功发送后会尝试补充语音；原文字保持正常发送。若内置「自动语音」已启用，则本插件跳过普通回复语音，避免两份语音。插件命令回执也不会被重复朗读。超出朗读上限时不偷偷截断，仍保留文字。

## 任务与发送规则

合成使用宿主队列、音色库和受管理资产。语音任务能在本机音频页查看、试听；QQ 侧不会自动打开本机播放器。

语音发送绑定原消息、账号、会话和主人。文字回执失败时不会尝试语音交付；切号、插件关闭、取消主人授权、卸载/重载插件或会话禁发后停止新交付。重复消息复用请求编号；有既有交付记录时不自动重发，包括结果不确定的情况。生成成功、平台回执和接收端实际可播放要分别验收。

这些检查在提交交付前再次执行；已经交给宿主发送器或QQ平台的请求可能无法撤销。插件设置保存本身不等于取消已开始的网络发送。

任务完成后的简要交付结果写到宿主运行记录。`语音 任务` 分别显示生成和交付：没有交付记录、平台已回执、待核实、部分交付，不能把“已生成”当作QQ已发送或收件端可播放。不确定结果不自动重试，重载后查询沿用宿主持久记录。发送未完成时请看本机任务/运行记录；不通过反复重发同一指令“补发”。如确实需要再次发送，由主人明确提交新消息，并承担新一次发送意图。

`语音 取消` 只针对同一主人、QQ账号和原会话中的排队或生成任务；已完成任务会给出不能撤回的明确提示。取消排队/生成后即使稍后到达文字回执，也不会自动交付已取消的任务。已经生成的音频仍按宿主管理资产规则保留，不能用此指令删除文件。

## 当前边界

- 本插件复用 5.1.2 的原生页面、音频网关与 Agent 状态组件，不在 ZIP 中复制或覆盖宿主核心文件。旧宿主会提示升级，不能仅靠此包增加完整控制台页面。
- 唱歌管线、设备配对向导尚未接线。输入 `语音 唱歌` 会明确提示不可用，不把朗读歌词当作唱歌。
- 不提供远程批准、解除急停、任意终端、屏幕/文件上传或云服务权限。
- 发布验证使用隔离宿主、假引擎和假 QQ 发送端；没有启动用户模型、真实发送 QQ 或执行电脑动作。上一轮默认本机端点未连通，安装后需要自行启动已有服务并验证。

本包不含聊天记录、QQ登录态、API Key、私人音色、模型权重或参考素材。许可见 LICENSE。
